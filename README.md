# WeLearn: Tempat Belajar Jadi Lebih Seru & Produktif! 🚀

Halo! Kenalin ini **WeLearn**, aplikasi belajar yang didesain biar kamu nggak bosen pas ngerjain tugas. Kami bawa pengalaman pake sistem operasi (OS) langsung ke browser kamu. Ada efek *glassmorphism* yang kece dan navigasi ala desktop yang premium.

## 🏁 Gimana Cara Mulainya?

### 1. Masuk ke Dunia WeLearn
Pas pertama kali buka, kamu bakal disuguhi intro sinematik yang cakep. **Scroll aja ke bawah** buat transisi ke desktop. Kamu bakal ngerasa kayak "masuk" ke dalem monitor lewat animasi zoom-nya GSAP yang mulus banget.

### 2. Area Kerja Kamu (Desktop Hub)
Begitu udah di dalem, ini yang bisa kamu lakuin:
- **The Dock**: Menu di bawah itu namanya Dock (mirip Mac). Kalo cursor dideketin, icon-nya bakal nge-zoom!
- **Main Window**: Klik icon apa aja di Dock buat buka fiturnya. Jendelanya bisa ditarik-tarik (*draggable*), dibuka barengan banyak, atau ditutup pake tombol merah di pojok kiri atas.

## 🛠 Fitur-Fitur Jagoan

### 📓 AI Smart Notes
Bosen nyatet manual? Pake ini aja! Ada panel AI yang siap bantu kamu buat **Ngerangkum**, **Cari Kata Kunci**, sampe **Bikin Flashcards** otomatis dari catetan kamu. Belajar jadi jauh lebih cepet!

### ⏳ Focus Space (Pomodoro)
Biar belajarnya nggak pecah fokusnya. Ada timer ala Pomodoro (`Focus`, `Short Break`, `Long Break`) lengkap sama musik ambient biar kamu makin tenang pas ngerjain tugas.

### ⚔️ Quest Log (Tugas Jadi Game)
Di sini, setiap tugas yang kamu selesain itu dianggap "Quest". Selesain tugasnya, dapetin **XP**, terus naikin Level kamu biar jadi *Master Scholar*! Ada bar progres-nya juga loh biar makin semangat.

### 👥 Peer Study Forum
Bingung sama soal susah? Tanya aja di sini! Kamu bisa liat thread berdasarkan mata pelajaran, kasih upvote ke jawaban yang bantu banget, dan ngobrol sama temen-temen belajar yang lain.

## ⚙️ Atur Sesuai Selera (Settings)

Klik icon **Settings** di Dock buat buka System Preferences:
- **Tampilan**: Mau **Light Mode** atau **Dark Mode**? Sikat! Kamu juga bisa atur efek blur-nya mau nyala atau nggak.
- **Wallpaper**: Kamu bisa ganti background desktop pake video-video keren yang udah kamu buka pake XP kamu.
- **Musik**: Atur soundtrack belajar kamu. Pilih lagu-lagu lo-fi favorit biar makin *vibing*.

## 💻 Buat Developer (Setup Teknis)

WeLearn dibuat pake teknologi modern: **Next.js 15+**, **TypeScript**, **Tailwind CSS**, dan **Framer Motion**.

### Cara Install:
1. Clone repo-nya.
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Jalanin server dev:
   ```bash
   pnpm dev
   ```
4. Buka [http://localhost:3000](http://localhost:3000) di browser kesayangan kamu.
